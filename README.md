# Orienta360 Online

Versione web sperimentale di Orienta360 per GitHub Pages.

La web-app lavora interamente nel browser: le foto vengono aperte dal computer dell'utente, elaborate localmente e risalvate come nuovi file JPG. Non richiede installazione e non invia le immagini a un server.

## Funzioni incluse

- apertura di una singola foto JPG 360;
- apertura di una cartella di foto, con filtro per probabili immagini 2:1;
- cambio vista con yaw, pitch, roll e zoom;
- salvataggio della foto orientata con metadati 360;
- mascheramenti privacy: volti, targhe, fotografo e Nadir;
- Nadir a mosaico o con logo importato;
- help integrato nell'interfaccia.

I video non sono inclusi in questa versione online.

## Pubblicazione con GitHub Pages

I file pubblicabili sono nella cartella `docs`.

Per attivare il sito:

1. aprire la repository su GitHub;
2. andare in **Settings > Pages**;
3. in **Build and deployment**, scegliere **Deploy from a branch**;
4. selezionare il branch `main` e la cartella `/docs`;
5. salvare.

Dopo la pubblicazione, GitHub mostrerà l'URL pubblico della web-app.
